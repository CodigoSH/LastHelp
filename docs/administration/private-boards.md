# Private organizations and projects

An organization or a project can be kept from the public, so a team can use LastHelp for work nobody outside it should see.

Everything is public by default. Nothing changes for an installation that does not touch the switch.

## Turning it on

Turn on **Only the team can see it** for an organization, or **Team only** for a project — when you create it, or later in its settings. Turn it off to make it public again; nothing is lost either way. An organization's switch hides every project under it, whatever their own setting says.

## What the public sees

A private project is not refused: it does not exist. The page, its reports, its form, its roadmap and its feed answer exactly as an address that was never created does, so the answer does not admit anything is there. It is also left out of the front page, the organization's list of projects and the search, and nobody outside can vote on it, comment on it or send a report to it.

## Who still sees it

The team that works on it: the administrator, the owners of its organization and the collaborators on that project. A collaborator on one project does not see a private project next door. They see it as usual in the panel, marked **Private** in the lists.

Reports already on a project keep their address, but it answers as missing for the public while the project is private.
