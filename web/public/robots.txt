# The public boards are meant to be found: that is what a feedback portal is
# for. What is behind a session, and anything carrying the token that opens
# somebody's own report, is not — and it is kept out by saying so on the page
# itself (X-Robots-Tag: noindex and a robots meta), not by forbidding the
# crawler to fetch it. A crawler that is not allowed to fetch an address never
# reads the noindex on it, and an address that is linked from elsewhere can then
# be listed anyway, without its page.

Allow: /
